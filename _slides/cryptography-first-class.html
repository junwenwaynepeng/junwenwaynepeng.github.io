I — The Basic Cryptographic Model

Alice
message $m$
Encrypt
$c=E_k(m)$
Public channel
adversary sees $c$
Decrypt
$m=D_k(c)$
Bob
message $m$

Correctness: $D_k(E_k(m))=m$.

Security: seeing $c$ should reveal almost nothing useful about $m$.

Time: 1.5 minutes. Emphasize two different questions: does it work, and is it safe?
