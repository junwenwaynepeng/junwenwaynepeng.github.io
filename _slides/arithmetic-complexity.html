--- layout: slide title: | Explicit Arithmetic Distance Motivated by Tits Alternative in Arithmetic Dynamics date: 2026-5-12 author: Wayne Peng (joint with You-Ting Chen) coauthors: to: National Central University description: Some slides for a git and GitHub workshop using reveal.js categories: academic abstract: | Motivating by the study of Tits alternative in arithmetic dynamics, we investigate the arithmetic distance between distinct rational maps $f,\ g: \mathbb{P}^1(\mathbb{Q})\to \mathbb{P}^1(\mathbb{Q})$ defined by $$\hat{\Delta}(f,g)=\sup_{x\in \mathbb{P}^1(\mathbb{Q})}|\hat{h}_f(x)-\hat{h}_g(x)|$$ Moreover, when $g$ is monomial, the arithmetic distance is invariant under conjugation by elements of $\operatorname{PGL}_2$. This motivate the definition of the arithmetic complexity of a conjugacy class $[f]$ in the moduli space $\mathcal{M}_d$ by $$\mu([f]) =\hat\Delta(f,g)$$ To compute this arithmetic complexity, we establish explicit and computable Hölder constants and exponents for the modified Green function with respect to the chordal metric. Under additional assumptions, we further obtain Lipschitz continuity. Using these analytic estimates, we develop a numerical algorithm to compute arithmetic distances between rational maps with good reduction at all finite places. The method combines a global coarse search with local optimization on $\mathbf{P}^1(\mathbb{Q})$. We then apply the algorithm to families of unicritical maps $f:x\mapsto x^d+c$ and find $\mu([f])$.
